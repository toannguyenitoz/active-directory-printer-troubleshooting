## ✅ Checks Completed

- [ ] Correct printer selected
- [ ] Printer online and not paused
- [ ] Paper, toner, doors and jams checked
- [ ] User tested from Notepad
- [ ] User's stuck jobs reviewed
- [ ] Client Spooler status checked
- [ ] Print server reachable on TCP 445
- [ ] Printer IP reachable
- [ ] Printer TCP 9100 tested
- [ ] Queue port and IP validated
- [ ] Driver validated
- [ ] Permissions and AD groups checked
- [ ] GPO result reviewed
- [ ] PrintService logs collected
- [ ] Server test page attempted
- [ ] Another user or workstation tested

## 🔎 Findings

> Record test results, timestamps, event IDs, queue status, port settings and observations.

## 🛠️ Resolution

> Describe the exact change made. Avoid vague notes such as “fixed printer” or “restarted service”.
